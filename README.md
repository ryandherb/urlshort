# urlShort
This is a personal learning project working with fastAPI to demonstrate automatic testing and deploying for a cloud-hosted application.

## The application
The actual application of this project is just a simple url-shortener. The actual app is simple on purpose to showcase the cloud-related features and automated testing. 

## The Meat & Potatoes
The actual "interesting" part of the project is everything that goes on behind the scenes. Automated testing, health checks, deployment rollback procedure and (eventually) a well updated README explaining the architecture.
